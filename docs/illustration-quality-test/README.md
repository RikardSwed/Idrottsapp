# Komprimeringstest för Flex-illustrationer

Testet använder den valda platta illustrationsstilen och jämför WebP och AVIF i praktiska mobilstorlekar. `index.html` visar samtliga varianter sida vid sida.

Rekommenderad standard är **WebP, 480 × 480, kvalitet 82**. Testfilerna är cirka 12,7–13,1 KB per trestegsbild. Vid 200 övningar motsvarar det cirka 2,6 MB innan variation mellan enklare och mer detaljerade illustrationer.

720 × 720 kan användas för övningar där händer, redskap eller små ledvinklar behöver mer detalj. AVIF är något mindre men ger mindre vinst än väntat för den här typen av enkel grafik och innebär fler kompatibilitetsfrågor.
